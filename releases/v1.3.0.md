Flex Zoom 1.3.0 adds configurable global shortcuts for zooming in and out while using another app or keeping settings in the tray.

- **Ctrl + Alt + Plus** (plus/equals key without Shift) zooms in; **Ctrl + Alt + Minus** zooms out.
- Each press changes magnification by 0.25x within the 1.25x–8x range. The current level saves automatically.
- Configure or disable zoom shortcuts independently from the lens toggle. Conflicting shortcuts are reported, and recording avoids triggering lens actions.
- Existing settings retain their values and acquire the default zoom shortcuts.

Validation: 86 interactive Windows assertions passed, including global keyboard delivery, native magnifier transforms, shortcut capture, conflicts, persistence, and limits. Cloud CI separately runs headless checks; it does not replace physical-device validation.

## Code signing policy

The release workflow requires SignPath Foundation signing and a verified timestamped Authenticode signature before uploading the portable ZIP. See the [Code signing policy](https://github.com/TeranceO/FlexZoom/blob/main/CODE_SIGNING.md) for provider, roles, privacy, and current onboarding status. SHA-256 checksums and build/signing provenance accompany signed assets. Signing does not guarantee immediate SmartScreen reputation.
